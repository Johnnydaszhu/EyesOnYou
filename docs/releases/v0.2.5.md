## EyesOnYou 0.2.5

### Route each app your way

- Choose **Follow System**, **Force Direct**, or **Force Proxy** from an app’s ranking-row menu.
- See whether the macOS system proxy is on, which endpoint it uses, and whether per-app rules are active.
- Keeps an explicit proxy rule from silently falling back to a direct connection when its proxy is unavailable.
- Restores the previous macOS HTTP and HTTPS proxy settings when routing is disabled or EyesOnYou quits.

### A clearer traffic overview

- Keeps the highest-traffic app at the top of the ranking and marks it with a crown.
- Rebuilds cumulative charts from the selected period’s history, so earlier traffic remains visible after opening the dashboard.
- Makes the version badge a direct link to the EyesOnYou project and its releases.

### Install

1. Download `EyesOnYou-0.2.5.dmg`.
2. Open the disk image and drag **EyesOnYou** into **Applications**.
3. Launch EyesOnYou from Applications and keep it running while you want traffic measured.

Per-app routing currently covers HTTP and HTTPS connections from apps that follow the macOS system proxy. Raw TCP, UDP, QUIC, and proxy-unaware apps still require a signed Network Extension.

The GitHub download is ad-hoc signed and is not notarized.
