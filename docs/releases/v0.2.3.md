## EyesOnYou 0.2.3

### What’s fixed

- Fixes major undercounting when a VPN or TUN route hides the app that owns part of the traffic.
- Keeps every measured byte: traffic that cannot be matched safely is now shown as **Unattributed** instead of being discarded.
- Fixes missed traffic when macOS interface counters pass 4 GB, while avoiding duplicate VPN-interface totals.
- Makes traffic storage retry safely after a write failure and prevents older totals from being added twice.
- Keeps the app responsive while project and session attribution is being discovered.

### Also new

- Adds a **Launch at Login** option so monitoring can start automatically.
- Warns when the selected time range began before EyesOnYou started monitoring.
- Shows direct, proxy, and Unattributed traffic separately in the dashboard and menu bar.

### Install

1. Download `EyesOnYou-0.2.3.dmg`.
2. Open the disk image and drag **EyesOnYou** into **Applications**.
3. Launch EyesOnYou from Applications and keep it running while you want traffic measured.

The GitHub download is ad-hoc signed and is not notarized. Network Extension features still require Developer ID signing and user approval.
