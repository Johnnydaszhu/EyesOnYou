## EyesOnYou 0.2.4

### More accurate traffic totals

- Keeps traffic rates correct after sleep, long sampling gaps, counter resets, and transfers larger than 4 GB.
- Distinguishes an unavailable connection scan from a genuinely idle Mac, so active traffic is not closed or reassigned by mistake.
- Improves app and project attribution while keeping uncertain traffic clearly marked as **Unattributed** instead of guessing.
- Makes IPv4 and IPv6 route rules match the intended address ranges more reliably.

### Faster and more resilient

- Moves dashboard summaries out of the foreground so live updates stay responsive with a long traffic history.
- Reduces repeated connection scans, database writes, browser checks, and menu bar refresh work.
- Adds firm time limits to system lookups so one slow macOS service cannot stall monitoring.
- Preserves new traffic safely while history is being saved or an app entry is being removed.

### Install

1. Download `EyesOnYou-0.2.4.dmg`.
2. Open the disk image and drag **EyesOnYou** into **Applications**.
3. Launch EyesOnYou from Applications and keep it running while you want traffic measured.

The GitHub download is ad-hoc signed and is not notarized. Network Extension features still require Developer ID signing and user approval.
